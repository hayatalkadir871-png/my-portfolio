# Hayat Alkadir Personal Portfolio

This is a clean, responsive personal portfolio website for Hayat Alkadir, an Applied Biology Science graduate from Bahir Dar University with an interest in programming, technology, and the intersection of science and software.

## Project Structure

```text
hayat-portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── assets/
```

## Files

- `index.html` includes all portfolio sections and content.
- `css/style.css` contains responsive styling and visual design.
- `js/script.js` contains interactivity such as responsive navigation, scroll reveal, filtering, contact validation, theme toggle, and smooth scrolling.
